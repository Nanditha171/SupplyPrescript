# Supply Prescript — Database Architecture & Administration

This directory contains the database definition, initialization scripts, seed dataset, and administrative documentation for the **Supply Prescript** closed-loop prescriptive analytics engine.

---

## 1. Database Purpose & Closed-Loop Lifecycle

The database captures every stage of the operational lifecycle:

$$\textbf{Predict} \longrightarrow \textbf{Prescribe} \longrightarrow \textbf{Decide} \longrightarrow \textbf{Execute} \longrightarrow \textbf{Measure} \longrightarrow \textbf{Learn}$$

1. **Predict**: Machine learning models estimate delivery delay probabilities and risk scores for supply events.
2. **Prescribe**: Optimization solvers generate multiple Pareto-ranked operational intervention strategies (e.g., Air Freight, Secondary Supplier, Launch Delay).
3. **Decide**: Human managers review options, approve recommendations, or submit overrides with documented rationale.
4. **Execute**: Warehouse and logistics teams execute the chosen action.
5. **Measure**: Actual costs, lead times, and SLA service levels are recorded and compared against optimizer estimates.
6. **Learn**: Variance errors generate learning signals and weight calibration adjustments for subsequent optimization runs.

---

## 2. Technology Stack

- **Database Engine**: PostgreSQL 15+
- **ORM**: SQLAlchemy 2.x (Declarative Mapped syntax)
- **Database Migrations**: Alembic
- **Driver**: `psycopg` (v3) / `psycopg2-binary`
- **Data Validation**: Pydantic V2
- **Environment Management**: `python-dotenv`

```bash

```

```bash

```

### Seed Realistic Operations Dataset

## 5. Schema Overview & Core Entities

| Table | Description | Primary Key / Index Highlights |
| :--- | :--- | :--- |
| `products` | Master SKU catalog with costs and criticality classifications. | `id` (PK), `product_code` (Unique), `product_category`, `criticality_level` |
| `suppliers` | Supplier profiles, geographical locations, reliability scores, and capacity. | `id` (PK), `supplier_code` (Unique), `supplier_country`, `risk_level` |
| `inventory` | Warehouse stock positions and available units. | `id` (PK), `(product_id, warehouse_code, inventory_date)` (Unique) |
| `supply_events` | Operational shipment records connecting suppliers, products, and baseline logistics. | `id` (PK), `event_id` (Unique), `product_id` (FK), `supplier_id` (FK) |
| `predictions` | ML delay classification and risk score inference outputs. | `id` (PK), `event_id` (FK), `prediction_type`, `risk_level` |
| `optimization_runs` | Prescriptive mathematical optimization solver runs. | `id` (PK), `optimization_run_id` (Unique), `event_id` (FK), `prediction_id` (FK) |
| `recommendations` | Alternative candidate strategies generated by the solver (e.g., ALT_A, ALT_B). | `id` (PK), `(optimization_run_id, recommendation_code)` (Unique) |
| `decisions` | Manager selections, approvals, overrides, and execution tracking. | `id` (PK), `decision_id` (Unique), `optimization_run_id` (FK), `recommendation_id` (FK) |
| `outcomes` | Actual realized costs, lead times, SLA metrics, and calculated variances. | `id` (PK), `decision_id` (FK, Unique), `evaluation_date` |
| `feedback` | Error signals closing the loop to adjust future solver parameters. | `id` (PK), `outcome_id` (FK), `optimization_run_id` (FK) |

## 6. End-to-End Demonstration Scenario

The database includes the canonical demonstration scenario for the Supply Prescript platform:

1. **Supply Event**: `EVT-2026-001` — Microchip X1 (`P001`) ordered from Pacific Silicon (`SUP-001`).
2. **Prediction**: XGBoost Classifier predicts **87% delay probability** and **14-day delay**.
3. **Prescription**: Solver generates 3 alternatives:
   - `ALT_A`: Expedited Air Freight ($15,000, Rank 1 - Recommended)
   - `ALT_B`: Secondary Supplier ($22,000, Rank 2)
   - `ALT_C`: Delay Launch Schedule ($0, Rank 3)
4. **Decision**: Manager approves `ALT_A` (Air Freight) to protect automotive assembly timelines.
5. **Outcome**: Air freight lands successfully in 2 days; unexpected jet fuel surcharge results in actual freight cost of **$18,000**.
6. **Feedback**: Cost variance **+$3,000** recorded with feedback learning signal: *"Incorporate +20% jet fuel seasonal rate multiplier into APAC air freight parameters."*

## 7. Auditability & Traceability

Every manager decision is 100% auditable via `src.database.crud.get_traceability_trail(db, decision_id)`:

$$\text{Supply Event} \rightarrow \text{Prediction} \rightarrow \text{Optimization Run} \rightarrow \text{Recommendations} \rightarrow \text{Decision} \rightarrow \text{Outcome} \rightarrow \text{Feedback}$$
